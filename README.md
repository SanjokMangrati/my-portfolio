# My Portfolio

My personal site, built with Astro and the Terrace design system (`design/terrace`).

Live at [smangrati.com](https://smangrati.com).

```sh
pnpm install
pnpm dev      # local dev server
pnpm check    # typecheck
pnpm build    # static build into dist/
```

The contact form posts to Web3Forms when `PUBLIC_WEB3FORMS_KEY` is set at build time.
