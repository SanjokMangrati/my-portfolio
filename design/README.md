# Design

`terrace/` is the locked design system for smangrati.com, approved on 2026-10-16.

- `terrace/README.md` — the brand book: voice, color, type, layout, motion, iconography and marks.
- `terrace/tokens.json` — every token with its value in both themes (Mist and Night estate) and where it is used.
- `terrace/lineage.md` — the five reference sites it was mixed from, and what each contributed.

The live reference with component previews is the Terrace design system in Claude Design:
https://claude.ai/artifact/7oHQdJbjaebtkg2oviFDPM (version 1792154315-e53e).

`src/styles/global.css` mirrors `tokens.json`. Change the tokens here first, then the stylesheet.
